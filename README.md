# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior using Python, data cleaning, and Power BI. The goal is to explore customer purchasing patterns, understand shopping preferences, and present useful insights through data analysis and visualization.

## Tools & Technologies

- **Python** — Data analysis and exploration
- **Pandas** — Loading, inspecting, and analyzing data
- **VS Code** — Data cleaning and Python development
- **Google Colab** — Python notebook development
- **Power BI** — Interactive dashboard and data visualization

## Project Workflow

1. **Data Loading:** Loaded the customer shopping behavior dataset into Python using Pandas in Google Colab.
2. **Data Exploration:** Inspected the dataset and reviewed its columns and records.
3. **Data Cleaning:** Cleaned and prepared the dataset using Python in VS Code.
4. **Data Export:** Exported the cleaned dataset to a CSV file.
5. **Dashboard Development:** Imported the cleaned CSV into Power BI to create visualizations and explore customer shopping behavior.

## Dataset

The dataset contains customer shopping information, including fields such as:

- Customer ID
- Age and gender
- Item purchased and product category
- Purchase amount (USD)
- Location
- Size and other shopping-related attributes

## Project Files

- `consumer_behaviour_analysis.ipynb` — Python notebook used for data exploration and analysis.
- `customer_shopping_behavior.csv` — Original dataset.
- `customer_shopping_behavior_cleaned_data.csv` — Cleaned dataset used for Power BI.
- `consumer_behaviour_dashboard.pbix` — Power BI report and dashboard.

## Key Objectives

- Explore customer demographics and purchasing patterns.
- Analyze purchase amounts across customer groups and product categories.
- Prepare a clean dataset for reporting and visualization.
- Build an interactive Power BI dashboard to communicate findings.

## How to Use This Project

1. Clone or download this repository.
2. Install Python and Pandas if you want to run the Python analysis locally.
3. Open the `.ipynb` file in Google Colab or Jupyter Notebook.
4. Ensure the original CSV file is available at the path used in the notebook.
5. Open the `.pbix` file in Power BI Desktop to explore the dashboard. If prompted, update the data source path to the location of the cleaned CSV file.

## Conclusion

This project demonstrates a basic end-to-end data analysis workflow, from exploring raw customer data and cleaning it with Python to building a Power BI dashboard for visual analysis.
